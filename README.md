# 육목 온라인 서버

육목(Connect6) 1:1 / 1:1:1 실시간 온라인 대전 + 컴퓨터 대전.
서버 한 개(Node.js)가 게임 화면과 WebSocket 통신을 함께 제공합니다.

```
yukmok-server/
├─ server.js          서버 (방 관리, 턴·6목 검증, 실시간 전달)
├─ public/index.html  게임 화면 (서버가 이 파일을 보내줍니다)
├─ package.json
└─ render.yaml        Render 배포 설정 (선택)
```

## 내 컴퓨터에서 실행해 보기

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 열면 됩니다.
같은 와이파이의 다른 기기는 `http://내컴퓨터IP:3000` 으로 접속하면 함께 할 수 있습니다.

## 인터넷에 올려서 친구들과 하기 (Render 예시)

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 올립니다. (`node_modules`는 올리지 않습니다 — `.gitignore`에 들어 있습니다.)
2. https://render.com 에 GitHub 계정으로 가입합니다.
3. **New → Web Service** 에서 방금 만든 저장소를 고릅니다.
4. 아래처럼 입력합니다.
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Health Check Path(선택): `/healthz`
   - Instance Type: Free
5. **Create** 를 누르고 몇 분 기다리면 `https://이름.onrender.com` 주소가 생깁니다.
6. 이 주소를 친구들에게 보냅니다.

`render.yaml` 이 들어 있어서 **New → Blueprint** 로 만들면 위 설정이 자동으로 채워집니다.
Railway, Fly.io 같은 서비스에서도 `npm install` / `node server.js` 만 지정하면 똑같이 동작합니다.
(서버는 `PORT` 환경변수를 자동으로 사용합니다.)

## 사용 방법

1. 한 명이 이름을 입력하고 **1:1** 또는 **1:1:1** 로 방을 만듭니다.
2. 화면에 나온 5자리 방 코드를 알려주거나, **초대 링크 복사** 로 링크를 보냅니다. 링크를 열면 코드가 자동으로 입력됩니다.
3. 나머지 인원이 같은 주소에 접속해 이름과 코드를 입력하고 **참가** 를 누르면 자리가 다 찬 순간 대국이 시작됩니다.
4. 새로고침하거나 잠깐 연결이 끊겨도 같은 자리로 돌아옵니다. 대국 중에 끊긴 플레이어는 상대 화면에 "연결 끊김"으로 표시됩니다.

## 알아둘 점

- 방 정보는 서버 메모리에만 있습니다. 서버가 재시작되면 진행 중인 방은 사라집니다. 사라진 방으로 돌아오려 하면 안내 문구와 함께 첫 화면으로 이동합니다.
- 접속한 사람이 아무도 없는 방은 1시간 뒤 삭제됩니다. 대국 시작 전에 접속이 30초 이상 끊기면 자리가 비워집니다.
- Render 무료 플랜 등은 접속이 없으면 서버가 잠들어 첫 접속이 느릴 수 있습니다. 화면은 자동으로 재연결을 시도합니다. 서비스별 무료 정책은 바뀔 수 있으니 가입할 때 확인하세요.
- 로그인/비밀번호는 없습니다. 주소를 아는 사람은 접속할 수 있고, 방 코드를 알아야 그 방에 들어갈 수 있습니다.
- 서버가 착수를 검증합니다. 내 차례가 아니거나, 돌이 있는 자리이거나, 게임이 끝난 뒤의 착수는 거부됩니다.
- `index.html` 파일을 더블클릭해서 직접 열면 온라인 대전은 안 되고 컴퓨터 대전만 됩니다. 온라인 대전은 반드시 서버 주소로 접속하세요.
